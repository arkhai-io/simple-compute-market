# Capacity independent-observer instruction

The observer agent is an independent evidence role. It is never the
deterministic controller and must not use controller-authored observations or
controller-owned source credentials.

Before the observation barrier, the agent must:

1. inspect this exact instruction at the pinned SCM commit;
2. prepare its independent source plan;
3. verify that its source authority is separate from every buyer, seller,
   host-operator, and controller process; and
4. bind owner-only native evidence through the contract's typed
   privacy-preserving bindings.

The agent remains alive through release, terminal observation, and the
declared observation barrier. It records only logical correlations, typed
outcomes, content digests, and privacy-preserving evidence bindings.

Never copy a wallet, account, listing, project, host, endpoint, VM, PCI, GPU,
credential, private evidence path, or native evidence value into a portable
SCM artifact.
