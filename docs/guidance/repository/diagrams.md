How this repository draws its diagrams, beside the shared rule on diagrams,

This repository's diagrams are drawn in draw.io: a diagram's `.drawio` source sits
beside its `.svg` export
([`diagrams.md`, "Source beside export"](../engineering/diagrams.md#source-beside-export)).
