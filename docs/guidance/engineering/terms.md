# Terms

How a repository with a defined vocabulary keeps one name per concept.

## One home per term

Each term is defined in one home, and a concept has one name. Use the established
term from its home; don't drift to a synonym the home rules out.

## A new term is defined where it first appears

A term new to the reader is defined where it first appears and marked as new.
